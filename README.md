# AI-агенты для продаж — лендинг

Одностраничный лендинг «цифровых продажников» на чистом HTML/CSS/JS.

## Что внутри

- **Блок 1 — Земля**: видео `planet.mp4` с привязкой к скроллу (`currentTime` → прогресс скролла), текст проявляется при прокрутке, стрелка «крути вниз».
- **Блок 2 — Мозг**: видео `brain.mp4` фоном + 3 направления (AI-продавцы / Цифровой след / Создание лендинга), контент проявляется скроллом.
- **Блок 3 — Контакты**: форма заявки.

## Ключевые техники

- `mix-blend-mode: screen` — чёрный фон видео (без альфа-канала) становится прозрачным, свечение остаётся.
- `position: sticky` + длинные секции (300–320vh) — паттерн scrollytelling.
- `requestAnimationFrame` + лерп `currentTime` — плавный скраб без рывков.
- `object-fit: contain` — квадратное видео мозга видно целиком (включая «полосу сердцебиения»).

## Запуск

Открыть `index.html` в браузере. Форма заявки — заглушка (константа `ENDPOINT` в коде).
